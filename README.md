- **Processador:** Intel Core i5/i7 (12ª geração+) ou AMD Ryzen 5000+
- **Memória:** 16 GB ou 32 GB RAM
- **Placa de Vídeo:** NVIDIA RTX série 30/40 ou AMD RX 6000/7000 dedicada

- **Memória:** Mínimo 12 GB RAM
- **Dica de Desempenho:** 
  - Mantenha em modo **Handheld** (720p).
  - Certifique-se de que a API gráfica esteja em **Vulkan**.
  - O pacote de shaders pré-compilados já evita grande parte dos engasgos nessas máquinas!

## 🚀 Como Usar

1. Baixe o pacote compilado na aba [Releases](https://github.com/guuhferiani/zelda-ocarina-oftime/releases).
2. Extraia o arquivo .zip em qualquer pasta do seu computador.
3. Coloque suas chaves (prod.keys) na pasta user/keys/ (ou em %APPDATA%\eden\keys\).
4. Abra o executável lichii.exe.
5. Adicione a pasta onde está o arquivo do jogo (.nup, .nsp ou .xci).
6. O perfil otimizado e os shaders já serão carregados automaticamente!
